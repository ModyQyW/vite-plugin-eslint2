## Introductions

`vite-plugin-eslint2` is a monorepo for the Vite ESLint plugin and the packages around it:

| Name                                                                              | Description                                               |
| --------------------------------------------------------------------------------- | --------------------------------------------------------- |
| [core](https://github.com/ModyQyW/vite-plugin-eslint2/tree/main/packages/core)    | The published plugin package                              |
| [docs](https://github.com/ModyQyW/vite-plugin-eslint2/tree/main/docs)             | Documentation site (Rspress)                              |
| [examples](https://github.com/ModyQyW/vite-plugin-eslint2/tree/main/examples)     | Examples integrated with specific frameworks or libraries |
